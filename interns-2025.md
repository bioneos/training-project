# Bio::Neos Training Project Challenges

## Challenge 1: Tiny Tweaks

**Branch**: `tiny-tweaks`

**Objective**: Make small UI modifications to learn the structure of the frontend code.

**Tasks**:
- [ ] Modify the application background gradient colors
- [ ] Change the theme toggle icons (currently sun/moon) in the navbar
- [ ] Update the navigation menu border styling and appearance
- [ ] Customize the welcome message format on the landing page
- [ ] Adjust the form input field styles (border radius, focus effects, placeholder text)
