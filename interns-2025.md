# Bio::Neos Training Project Challenges

## Challenge 1: Troubleshooting

**Objective**: Find and fix the intentionally introduced runtime error in the codebase.

**Instructions**:
1. Check out the troubleshooting branch: `git checkout troubleshoot`
2. Run the application and try to use the account management features
3. Identify the runtime error that occurs, and when it happens
4. Fix the error (Comment if you need to)
5. Push your changes
